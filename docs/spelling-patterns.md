# Spelling Star — What Each List Is Teaching

Every list in `wordlists/spelling/` is built around a pattern, although the
lists never say which one. This file names the pattern for all 60 lists (§1), then
gives five full lessons that teach the pattern itself rather than the 15–18 words (§2).

**Why bother:** a child who memorizes `swimming` knows one word. A child who
knows *why* `swimming` has two m's can spell `hopping`, `planning`, and
`skipping` without ever studying them. The words on a list are examples. The
pattern is the thing to learn.

**Status:** Content only. The five lessons are written so a parent can teach them
from this page. Nothing in the app reads this file yet (see §3).

---

## 2. Five lessons

All five lessons follow the same steps. Each takes about 15 minutes, before the child
first sees the list in Study.

1. **Sort.** Give the child the words on slips of paper or a whiteboard and have them
   sort the words into groups. Don't name the rule yet. A child who finds the pattern
   remembers it better than one who is told it.
2. **Say it.** Help the child put the rule into one sentence of their own.
3. **Why.** Explain why the spelling works this way. Knowing the reason makes the rule
   easier to remember.
4. **Try new words.** Spell words that are *not* on the list. This shows whether the
   child has learned the rule or only the list.
5. **Rule-breakers.** Look at the words that don't fit and talk about why.

A lesson has worked if the child can spell the new words in step 4. The next spelling
test only shows whether they learned the list.

---

### Lesson A — List 3.8: Adding -ing and -ed

**The idea:** Before you add an ending, look at how the word ends. There are
three moves: **double**, **drop**, or **just add**.

**1. Sort.** Write each base word next to the list word:

| | | |
|---|---|---|
| swim → swimming | come → coming | end → ended |
| get → getting | have → having | start → started |
| | joke → joked | do → doing |
| | receive → received | happen → happened |
| | smile → smiled, smiling | happen → happening |

Ask: *"What happened to the base word each time? Make piles."* The child should
end up with something like *"doubled a letter"*, *"lost the e"*, and *"nothing
changed."* (`swam` has no ending. It's the past tense of swim, which makes a
good conversation about how some verbs don't use -ed.)

**2. Say it.**
- **Drop:** word ends in a silent e → drop the e, then add -ing or -ed.
- **Double:** short word, **one** vowel, **one** consonant at the end → double
  the last letter (`swim` → `swimming`). This is the "1-1-1 rule."
- **Just add:** everything else, such as two consonants at the end (`end`, `start`) or no
  final consonant (`do`).

**3. Why.** The doubled letter keeps the vowel short. Write these
pairs and have the child read them:

> hopping / hoping  ·  tapping / taping  ·  dinner / diner

With one consonant, the vowel "sees" the next vowel and says its name: *ho-ping*.
Two consonants block it, and the vowel stays short: *hop-ping*. So if
`swimming` had only one m, it would read *swy-ming*. The silent e drops for
a related reason: the -ing already has a vowel that makes the first vowel long,
so the e isn't needed anymore (`smile` → `smiling`).

**`happened` doesn't double**, although it ends in one vowel and one consonant.
The rule is about short words, or more precisely about the *stressed* syllable.
Say HAP-pen: the stress is at the front, so nothing doubles. Compare
be-GIN → be-GINNING, where the stress is at the end. This is for a curious
child only. "It's two syllables" is enough for now.

**4. Try new words** (say each one and have the child write the -ing and -ed forms):

> hop, hope, plan, bake, jump, shop, ride, rain, tap, tape, skip, wave

Answers: hopping/hopped, hoping/hoped, planning/planned, baking/baked,
jumping/jumped, shopping/shopped, riding, raining/rained, tapping/tapped,
taping/taped, skipping/skipped, waving/waved. (`rain` just adds: it has two vowels.)

**5. Rule-breakers.** `received` is on this list for its *ei*, which is Lesson D.
Its ending follows the drop rule like the others.

### Lesson B — List 3.15: oi or oy?

**The idea:** `oi` and `oy` make the same sound. Where the sound falls in the word
tells you which one to use.

**1. Sort.** Two columns, `oi` and `oy`:

| oi | oy |
|---|---|
| pointing, oily, voice, joined, coin, choice, poison | boy, destroy, enjoy, oyster, voyage, loyal |

Put `choose` and `chocolate` aside for now. Ask: *"Look where the oi is in each word.
Now look where the oy is."*

**2. Say it.** **oi** goes in the **middle** of a word. **oy** goes at the
**end** (`boy`, `enjoy`, `destroy`).

**3. Why.** English words almost never end in the letter **i**. When a word
needs that sound at the end, it uses **y** in place of i. This also explains
other spellings the child already knows:

| middle | end |
|---|---|
| r**ai**n | pl**ay** |
| c**oi**n | b**oy** |
| (th**ei**r) | th**ey** |

This one fact explains three spelling patterns, so it is worth spending time on. The
exceptions are mostly borrowed words like *taxi*, *ski* and *spaghetti*.

**4. Try new words:** `toy`, `soil`, `joy`, `boil`, `point`, `annoy`, `noise`,
`employ`, `spoil`, `ahoy`, `coil`, `royal`.

**5. Rule-breakers.**
- `voyage`, `loyal`: oy in the middle, but right before another vowel.
  *oi* followed by a vowel would be hard to read (*voiage*), so oy also goes
  before a vowel.
- `oyster`: a real exception.
- `oily`: oil + y, so the oi is in the middle of `oil` like it should be.
- `choose`, `chocolate`: they don't have the /oi/ sound at all. They're on the list so the
  child has to listen. *"Do you hear /oi/? Then it's not oi or oy."*

### Lesson C — List 3.20: Soft c and soft g

**The idea:** **c** and **g** each have two sounds. The letter right after
them tells you which sound to use.

**1. Sort.** Sort by **sound** first. Say each word and ask whether the c sounds
like /s/ or /k/, and whether the g sounds like /j/ or /g/:

| c says /s/ | c says /k/ | g says /j/ | g says /g/ |
|---|---|---|---|
| city, cereal, face | could, coast, clean, carton | huge, age, danger, giant | goose, gone, guard, guess |

Then: *"Circle the letter right after each c and g."* The soft ones are followed by
**e, i, y**, and the hard ones by **a, o, u** or a consonant.

**2. Say it.** **e, i, and y make c and g soft.** Before any other letter, c and g stay hard.

**3. Why.** These words came into English from French and Latin, where c and g had
already softened in front of e and i. English kept the spelling and the sound.
This also explains why silent e is on the end of `face`, `huge`, and `age`. The e
does two jobs. It makes the vowel long, and it keeps the c or g soft. Without it,
`face` would end with /k/ and `huge` would end with /g/.

**4. Try new words.** First have the child predict the sound, then spell the word:

> cent, cup, ice, cycle, cot, gem, gum, gym, page, game, cage, gentle, giraffe

**5. Rule-breakers.** One more fact makes the list make sense:
- `guess`: g is before e, so it *should* be soft (*jess*). The **u** is
  there as a wall between g and e to keep the g hard. The u makes no sound of its own.
  Other examples: `guest`, `guide`, `guitar`.
- `guard`: g is before u anyway, so the wall isn't needed. The spelling came
  from French.
- **g is less reliable than c.** The rule always works for c, but some common g words
  break it: `get`, `give`, `girl`, `gift`. If the child has trouble here, say: "c always follows the rule; g
  usually does."

### Lesson D — List 5.19: ie or ei, and adding endings to y and e

**The idea:** There's a famous rhyme for ie/ei. It works best if you use it only
when the word says **/ē/**.

**1. Sort.** First sort by spelling, then by sound:

| ie | ei after c | ei saying /ā/ | ei, other |
|---|---|---|---|
| piece, field, fierce, siege | receive, receiving | weigh, weighs | their, neither |

**2. Say it.**
> *i before e, except after c, or when sounding like ā, as in neighbor and weigh.*

Then make it more exact: **if you hear /ē/, write ie, unless it comes right after c.**
`piece`, `field`, `siege` (ie) and `receive` (after c) all follow it.
`weigh` doesn't say /ē/, so the rule doesn't apply. That's what the rhyme's
second half is about.

**3. Why the strict version.** The rhyme has many exceptions when it's used for every
ie/ei word: *their, height, weird, science, seize*. Most of them don't say /ē/.
If the child uses it only for /ē/, it works almost every time. That makes it a
rule the child can rely on.

**4. The second half of the list: adding endings.** This builds on Lesson A,
with one new part for y:

| Base | + ed / es | + ing | What happened |
|---|---|---|---|
| try | tried | trying | y → i ... **except before -ing** |
| hurry | hurried | | y → i |
| worry | worries | | y → i |
| write | | writing | drop the e |
| have | | having | drop the e |
| tire | tired | | drop the e |
| receive | | receiving | drop the e |
| plan | planned | | double (1-1-1) |

**Why y stays before -ing:** changing it would put two i's in a row:
*tri-ing*. English avoids double i (except in `skiing`, which is in list 5.11).

**Try new words:** `chief`, `believe`, `ceiling`, `deceive`, `thief`, `shriek`,
`eight`, `vein`. Then add endings to `carry`, `copy`, `cry`, `deny` (-ed and -ing),
and `smile`, `stop`.

**5. Rule-breakers.** `neither` (also said *nee-ther*) and `seize` are the
real exceptions to the /ē/ rule. The child should memorize them as exceptions.
`their` doesn't say /ē/, so it doesn't break the rule.

### Lesson E — List 5.28: Greek and Latin roots

**The idea:** Long words are often built from short parts that each have
a meaning. If you know the parts, you can spell the word, and you can often work out
what it means.

**1. Sort.** Give the 18 words and ask the child to find the part that repeats:

| geo | graph | auto | port | cycl | act |
|---|---|---|---|---|---|
| geology, geometry, geography, geologist | geography, autograph, telegraph, photograph | autograph, automobile, automatic, autobiography | transport, import, portable | bicycle, cyclone, encyclopedia | action, enact |

Some words belong in two piles. Point this out: it means the words are made of parts.

**2. Say it.** Build the meaning table with the child:

| Part | Means | Part | Means |
|---|---|---|---|
| geo | earth | -logy | study of |
| graph | write, draw | -ist | person who |
| auto | self | metr | measure |
| port | carry | tele | far |
| cycl | circle, wheel | photo | light |
| act | do | bio | life |
| trans | across | bi | two |
| im- | in, into | mobile | moving |
| -able | can be | en- | to make |

Then take some words apart:
- **geo + metry** = *earth-measuring.* Egyptians invented it to re-measure their
  fields after the Nile flooded each year.
- **auto + bio + graphy** = *self-life-writing*: a book you write about your own
  life.
- **photo + graph** = *light-drawing.* A camera draws with light.
- **auto + mobile** = *self-moving*: a carriage that moves without a horse.
- **port + able** = *can be carried.*

**3. Why.** For long words, roots help more than sounds. The schwa (list 5.15)
hides vowels in long words. You can't hear the second o in
*ge-OL-o-gy*. But if you know it's *geo + logy*, you know the letters.

**4. Try new words.** Have the child write each word and say what it means:

> biology, telephone, telescope (scope = look), export, report, tricycle,
> recycle, biography, paragraph, react, actor, autopilot

Then the reverse: *"What would you call the study of life? A person who studies
the earth? A machine that writes far away?"* (biology, geologist, telegraph)

**5. Rule-breakers.** `encyclopedia` is *en + cycl + paedia*, "the whole
circle of learning." The child doesn't need to spell paedia from its root. The
point is that cycl is there and keeps its y.

## 3. What would come next

- **Try these five first.** If they work, the other 55 lists follow the same
  five steps. The §1 table already has each list's pattern and rule-breakers.
- **In the app.** Lists already have a `desc` field that Study shows under the
  list name (`renderStudy()`). The quickest step is to put each list's
  one-line idea in `desc`, so the child sees it every time they study. A
  fuller version would add a "Learn the pattern" screen before Study, built
  from the sort and try-new-words steps. The try-new-words step works well as a
  game, because it uses words that aren't on the list and so it can't affect a grade.
